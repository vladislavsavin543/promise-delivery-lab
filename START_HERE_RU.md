# С чего начать

1. Открой reports/dashboard.html или open_dashboard.cmd.
2. Выбери штат SP, затем 2018 год. Объясни, какие знаменатели изменились.
3. В блоке модели переключи бюджет с 20% на 5% и 50%.
4. Прочитай начало reports/REPORT_RU.md и METHODOLOGY_RU.md.
5. Разбери SQL: товары, платежи и отзывы сначала агрегируются по отдельности.
6. Пройди выполненный notebooks/01_delivery_analysis.ipynb.
7. Запусти python run.py и python -m pytest -q.
8. Ответь на вопросы INTERVIEW_RU.md без подсказок.

В резюме можно описать учебное исследование, SQL, анализ качества доставки,
временную проверку модели и интерактивный дашборд.
Коммерческое внедрение и предотвращённые задержки не проводились.
