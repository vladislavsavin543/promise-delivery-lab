# Источники и словарь данных

Автор: **Olist**, Brazilian E-Commerce Public Dataset, версия 2.
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Лицензия на странице Kaggle API: CC BY-NC-SA 4.0.
Версия опубликована 1 октября 2021 года; сами заказы относятся к 2016–2018 годам.
URL архива, версия, размеры и SHA-256 восьми файлов зафиксированы в data/manifest.json.
Контрольные суммы зафиксированы в проекте по загруженному официальному архиву,
а не объявляются отдельно опубликованными контрольными суммами Olist.

## Ключи и кардинальности

- orders.order_id — уникальный заказ.
- orders.customer_id → customers.customer_id; customer_unique_id нужен для повторных покупателей,
  но в этом проекте не используется как предиктор.
- items.order_id, payments.order_id, reviews.order_id — отношения «многие к одному» к заказу.
- items.product_id → products.product_id.
- items.seller_id → sellers.seller_id.

Уникальность справочников и внешние ключи проверяются до JOIN.
Анонимные идентификаторы покупателей и строки заказов не входят в публичное демо.

## Даты и поля

- order_purchase_timestamp — время оформления.
- order_estimated_delivery_date — обещанный день в опубликованном снимке.
- order_delivered_customer_date — фактическое получение; только для целевой переменной.
- order_delivered_carrier_date — фактическая передача перевозчику; исключена из признаков.
- shipping_limit_date — крайний срок передачи; исключён из признаков.
- price — цена товарной позиции; freight_value — стоимость её доставки, валюта BRL.
- payment_value — сумма платежа; заказ может иметь несколько платежей.
- review_score — оценка 1–5; review_answer_timestamp — время ответа.
- customer_state / seller_state — коды бразильских штатов, например SP — Сан-Паулу, RJ — Рио-де-Жанейро.
- product_category_name — исходная категория. Для отчёта используются перевод и русские подписи.

Даты сравниваются в наивном локальном представлении источника;
часовой пояс не реконструируется. Для опоздания используются календарные дни.

## Статусы

delivered — доставлен; canceled — отменён; shipped — передан в доставку;
unavailable — недоступен; invoiced — выставлен счёт; processing — обрабатывается;
created — создан; approved — подтверждён.

Истории изменения статусов и обещанной даты нет. Поля справочников не имеют временных версий.
Доступность признаков при оформлении необходимо подтвердить отдельно перед внедрением.
