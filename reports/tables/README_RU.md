# Словарь итоговых таблиц

| Файл | Смысл |
|---|---|
| monthly.csv | Сроки и отмены по месяцу оформления |
| operational_cube.csv | Месяц × штат; агрегаты для фильтров дашборда |
| states.csv | Штаты с минимум 200 доставками |
| categories.csv | Основные категории с минимум 100 доставками |
| seller_watchlist.csv | Продавцы с минимум 100 однопродавцовыми доставками |
| review_comparison.csv | Низкие отзывы при своевременной и поздней доставке |
| order_statuses.csv | Статусы всей основной когорты |
| model_selection.csv | Качество кандидатов на валидации |
| test_model_metrics.csv | Отдельный тест, бюджет 20% |
| test_capacity.csv | Тест при разных долях приоритета |
| calibration.csv | Средний прогноз и частота события в группах теста |
| feature_importance.csv | Снижение AP при перемешивании на валидации |

## Ключевые поля

orders — все заказы; delivered — доставки с валидными датами;
late — опоздания по календарной дате; canceled — отмены;
late_rate — late / delivered.
delivery_days — дни от оформления до получения.
items_value — стоимость товаров, freight_value — стоимость доставки; BRL, не прибыль.
low / high — индивидуальные 95% границы Уилсона.

В operational_cube поля *_sum позволяют пересчитать среднее после фильтров.
reviewed_timely / reviewed_late — число последних ответов после доставки;
low_timely / low_late — из них оценки 1–2.
Статусы исходной когорты в интерфейсе не фильтруются и явно подписаны.

## Метрики модели

average_precision — AP; roc_auc — ROC-AUC; brier — среднеквадратичная ошибка вероятности;
log_loss — логарифмическая потеря.
prevalence — частота опозданий оцениваемой выборки.
priority_n — число заказов в приоритете; priority_late — опоздания в нём.
precision_at_budget — доля опозданий в выбранных заказах;
recall_at_budget — доля всех опозданий, попавших в выбор;
lift_at_budget — precision_at_budget / prevalence.
coverage — заданная доля приоритета, округляемая вниз до целого числа заказов.

У случайного приоритета показатели усреднены аналитически; priority_late отсутствует.
У правила короткого срока нет вероятностного смысла, Brier и log_loss не показываются.
model_selection.csv и test_model_metrics.csv используют 20% бюджет.

Важность признака — потеря AP после его перемешивания. Это не причинная сила.
Имена столбцов сохраняются на английском для воспроизводимости;
подписи интерфейса и пояснения написаны на русском.
